# Cleaning Payroll App (Indiana)

A modern Android payroll manager for cleaning LLCs, built with Kotlin. Generate paystubs, track hours and wages, and handle tax calculations for Indiana.

## Features
- Employee management (add, edit, archive)
- Manual and punchclock hours entry
- Automatic gross/net wage calculation
- Indiana and federal tax withholding (FICA, FUTA, State)
- PDF paystub generation
- History and basic reporting

## Roadmap
- User authentication
- Cloud backup
- Multi-user support

## Tech stack
- Kotlin, Jetpack Compose UI
- Room (SQLite) local database

---

## How to Use
1. Clone this repo
2. Import in Android Studio
3. Build & Run on your device or emulator
